React FAQ Accordion

Questo progetto è un semplice componente Accordion per FAQ realizzato con React. Permette di mostrare una lista di domande frequenti (FAQ) dove ogni domanda può essere espansa o compressa cliccando su di essa.

Cosa fa il codice:

Mostra una lista di FAQ numerate.

Permette di aprire e chiudere ogni domanda singolarmente.

Cambia l’icona da + a - quando un item è aperto.

Tecnologie utilizzate:

React per la gestione dei componenti.

useState per controllare lo stato di apertura/chiusura di ogni FAQ.

HTML e CSS per la struttura e lo stile base dell’accordion.
